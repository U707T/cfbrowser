这一版把内置浏览器补成能日常用的样子：书签可以搜索、导入导出，地址栏能换搜索引擎，网页打不开时不再是白屏，误关的标签也能找回来。

### ⭐ 书签：能搜、能带走

- 书签页顶部新增搜索，标题和网址都能匹配，不用再一条条翻。
- 支持导入浏览器导出的书签 HTML（Chrome、Edge、Firefox、Safari 都行），可选「合并」或「替换」，重复网址自动跳过。
- 也能导出成同样的 HTML 交给别的浏览器，或导出 JSON 备份留着自己恢复。
- 每条书签可以左滑改名、分享链接或删除，改标题只改标题，不会把收藏时间弄丢。

### 🔍 地址栏换个搜索引擎

- 「更多 → 搜索引擎」可在 Bing、百度、Google、DuckDuckGo、搜狗之间切换，首页和页面里的地址栏同时生效。
- 输入的是网址就直接打开，输入的是词才去搜索，规则和以前一样。

### 🌐 打不开的网页有话说

- 以前断网或域名解析失败只会停在一片空白；现在会说明是哪个站点没打开、给出原因，并提供「重试」和「返回上一页」。
- 只有整页加载失败才会显示这个提示，图片、统计脚本这类零碎资源失败不会打断阅读。

### 🗂 误关的标签能找回来

- 关掉标签（包括「全部关闭」）后，可以从首页菜单、页面菜单或标签面板里重新打开，地址、标题、桌面版设置和历史都还在。
- 无痕标签和空白标签不会被记住，也不会在重启后冒出来。

### 🛠 顺带修的

- 应用内「检查更新」以前查的是上游项目，可能推来一个装不上的包；现在只查本项目正式版。
- 下载大文件时的分段校验更严格：服务端没有可靠校验值就退回单连接，避免拼出新旧混合的文件。
- 冷启动顺序修正：先恢复自定义加速范围再启动网关，Windows 上等代理定下来再创建浏览器环境。
- 首页快捷入口不再为了显示图标提前访问各站点。
