# cfbrowser 还缺什么（2026-11-27）

本清单只列**当前确实没有**的能力，不重复已修项。基线 `1.3.1`。

## 一、浏览体验

### 1. 切标签与返回时的页面状态

- **切标签会重建 WebView**：只保留 URL 与 URL 级历史，滚动位置、未提交的表单、视频播放进度全部丢失。标签面板的提示文案已经如实写明这一点。
- **同标签内后退也可能重载**：项目没有显式打开 Android BFCache（`WebViewCompat.setBackForwardCacheEnabled`），`goBack()` 多数情况下会重新请求文档、重新执行 JS。
- **设计文档仍是规划**：`docs/bfcache-design.md` 描述了 L1 标签保活 / L2 原生 BFCache / L3 冷恢复三层，代码一行未落。这是浏览器体验上最大的缺口。
- **无滚动位置持久化**：进程被杀后重启只恢复标签的 URL，不恢复读到哪儿。

### 2. 页面能力

- **没有阅读模式**：无法剥离导航与广告只留正文。
- **没有网页离线保存**：不能把当前页面存成本地可离线打开的副本（现有的「导出」只针对论坛话题，不是通用网页）。
- **没有站点权限管理**：摄像头、麦克风、定位、通知等权限只能走系统弹窗，App 内没有「某站点已授予什么」的列表，也不能撤销。
- **没有站点数据管理**：无法按站点清除 Cookie / localStorage，只能整体清理（设置 → 数据管理）。
- **没有下载断点续传**：现有分段下载是单次会话内的并发加速，进程重启后从头开始。
- **WebView 下载只接 `onDownloadStarting`**：`blob:`、POST 提交、依赖页面内会话的下载可能拿不到，未做真机验证。

### 3. 书签与历史

- **没有目录 / 分组**：书签是平铺列表，只能搜索，不能建文件夹。
- **不能同步**：书签、历史只在本机 SharedPreferences，没有导出到云端或与浏览器账号互通（导出文件是手动的）。
- **历史没有按站点聚合**，也没有「清除最近一小时」这类时间范围清理。

### 4. 地址栏与搜索

- **没有搜索建议**：输入时不联想，也没有历史补全下拉。
- **没有隐私搜索选项**：只能换引擎，不能按次临时切到无痕搜索。
- **没有快捷指令**：不支持 `!bang`、自定义关键词触发等写法。

## 二、平台与兼容

- **桌面端仍是预览**：Windows（WebView2）与 Linux（WPE）共用连接层，但没有做过系统性的交互验收；Linux 明确不提供无痕标签（WPE 无 incognito 实现，无痕只做到不写历史）。
- **桌面端不支持浏览器指纹**：原生库没编 `browser-tls`，设置里的开关在桌面不生效。
- **没有 iOS / macOS**：上游这两个平台的代码在移植时已移除。

## 三、网络层

- **Rust 子模块停在 `f584d0e`**：上游 `f584d0e → e85040f` 含两条断网恢复修复，需要重编 Android 原生库并做连接回归，本轮未跟。
- **只对启用 ECH 的 Cloudflare 站点有效**：托管在其他 CDN 或未开 ECH 的站点，加进加速范围也只是隧道直通，不会更快。
- **多域名共用一个赢家 IP**：竞速只针对范围里的第一个域名，站点分布在不同 CF 区域时可能不是各自最快。
- **没有定时重测**：只在切网、赢家连续失败或手动触发时重新优选。

## 四、工程与验证

- **全量测试不是全绿**：`flutter test` 有数百项失败，其中一部分确认是缺 Windows 原生库（`quickjs_c_bridge.dll`、`doh_proxy.dll`），其余需要在补齐原生组件后逐项归因。
- **没有真机验收记录**：手势返回、收藏导入、失败页、搜索引擎跳转、覆盖安装都只有逻辑与单元测试，没有 Android 实机结论。
- **没有端到端测试**：没有集成测试覆盖「打开页面 → 收藏 → 重启 → 仍在」这类完整链路。

## 五、优先级建议

| 顺序 | 事项 | 理由 |
| --- | --- | --- |
| 1 | Android BFCache 开关 + `pageshow.persisted` 探针 | 改动最小，直接改善「同标签后退」这个最高频场景 |
| 2 | 有上限的后台标签保活 | 解决切标签白屏与丢状态，需要先拆 `webview_page.dart` |
| 3 | 滚动位置持久化 | 冷重启后能回到原位置 |
| 4 | 书签目录 / 分组 + 导入去重策略细化 | 书签变多后的整理需求 |
| 5 | 站点权限与站点数据管理页 | 隐私可控性 |
| 6 | Rust `e85040f` 跟进 | 断网恢复，需要单独一轮构建与连接回归 |
| 7 | 阅读模式 / 网页离线保存 | 体验增强，工作量较大 |

前四项都属于「恢复与数据带走」，收益最直接；阅读模式与离线保存可以往后放。
